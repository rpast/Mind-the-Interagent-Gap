# resources/

Drop source documents here: papers, reports, incident write-ups, exported datasets.

- One file per source. Name files `<firstauthor-or-org>-<year>-<short-title>.<ext>`, e.g. `hammond-2025-multi-agent-risks.pdf`.
- Agents treat these files as the primary sources for the ontology and incidents. Cite a claim by file name and page.
- Check a document's licence before committing it to a public repo. If in doubt, keep it local and add it to `.gitignore`.
- The curated list of links (not documents) is in `../RESOURCES.md`.
