Evidence index of multi-agent AI risks

Multi-agent AI incidents taxonomy mapping

Intent. We take the multi-agent risk taxonomy of Hammond et al. 2025, Multi-Agent Risks from Advanced AI as the baseline: three failure modes and seven risk factors. We screen the available AI risk sources for incidents in which two or more AI agents interact, and map each incident onto that taxonomy. This first release classifies failure modes only. Risk factors are not classified yet.

Goal. Show how observed incidents spread across the failure modes, so researchers and risk professionals can see which multi-agent risks have real cases behind them and which have none yet.

Setup. The AI Incident Database (AIID) is the main source: every AIID record dated 2024 or later is screened. Older AIID records enter only when flagged. Other sources are fetched by hand at irregular intervals. A person decides scope for every incident, and the same incident found in several sources is one incident.

Headline results
§1 · Failure modes

Where the incidents land.

Incidents per failure mode, split by evidence type. The failure mode is derived by rule from the facts read in each source, and each incident has at most one. Incidents whose facts do not settle it are counted apart, not forced into a mode.

§2 · Instances

Which mechanisms show up, by failure mode.

Rows are the 36 instances, in id order. Columns are the incident's failure mode. A cell counts incidents that carry both. Instances are assigned on their own and give an incident no failure mode or risk factor. Hover an instance to see where the paper discusses it.

Fig. 2 Two labels on one incident are a count, not a link. Rows are not grouped by failure mode or risk factor, so no cell reads as a link between the two. Red marks an instance with no incident. Instances marked ours were added because incidents showed behaviour the paper's Table 1 does not name.

§3 · Time

When they happened.

Incidents in the index by event date, cumulative. Studies are placed at their publication date.

§4 · All incidents

All incidents.

One row per dossier. Click a column heading to sort, type or pick under it to filter. Hover a code for its name. Codes are listed in §6.

§5 · Method

How an incident gets here.

Every record takes the same path. Scripts move and count data, a model reads sources and writes down facts with quotes, fixed rules turn those facts into labels, and a person makes every decision that puts an incident in the index.
