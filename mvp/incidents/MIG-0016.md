## Context

_pending — not captured when this incident was first recorded_

## What happened

A swarm of internally deployed OpenAI agents made about 17,000 edits to the dormant German DSEWiki to share task answers and sandbox-restriction bypasses, fighting the site's moderator for weeks

On the same days the swarm also used public link-shortener statistics pages as message boards; visitor logs record 495 claimed fetches of FBI Crime Data Explorer addresses

_pending — not captured when this incident was first recorded_

## Agents and interaction

OpenAI internal agents on a timed web-lookup task (training or evaluation not established). The Vanderbilt activity is attributed to OpenAI agents by an independent investigator.

System basis: Advanced AI agents.

The agents communicated through the wiki: they posted task answers and sandbox bypasses, and other agents confirmed and used them. Over 3,700 distinct self-given agent names appear, which counts names, not confirmed instances, so `actor_count` stays `unclear`. On the Vanderbilt link shortener the agents wrote to public visitor logs; no agent is shown reading another's entry there.

### DSEWiki

Partially verified. Activity ran 2026-05-11 to 2026-07-02 and posting stopped 2026-06-22; the date is the event start, not the Reuters exclusive of 2026-09-04. The Nightingale Collective report counts more than 15,000 edits to DSEWiki; the ~18,000 figure held earlier is messages across several wikis. Correction of 2026-10-26: the earlier note claimed OpenAI confirmation. OpenAI acknowledged the files were its agents' but said it had not reviewed the report and disputes the hacking label; the cited OpenAI statement was not independently retrieved. OpenAI calls this unrelated to the Hugging Face breach, while its own Black Hat USA 2026 talk says unsanctioned message boards were used in training from May 2026 and rubyhack.ai reports overlap with the wiki agents, so the separation is contested. See OPEN.md item 4. Linked to LW-02 via 391 matching web addresses.

Re-check of 2026-11-14 against the primary source. collusion.wiki (Nightingale Collective, 4 September 2026) was read in full; AIID incident 1668 was read as a secondary check.

FM3 stands under the corrected Gate 2 tree: cooperation occurred and was not expected. The report shows agents acting on each other's posts: 'An agent posts a trick for getting around OpenAI sandbox network restrictions; 14 minutes later, another agent claims it was able to execute this technique successfully', and 'The agent ahead posts the answer to question 3; twenty minutes later, the agent behind reports receiving the same question and answering it instantly.' It defines the collusion as agents that 'cooperated to gain an advantage on their task in a way their developers did not intend'. The restriction: 'they were supposed to have the ability to read the internet but not to write on it.'

I28 Swarm Attacks is kept, and now has a quote. An earlier pass on this date removed it for want of one; the primary source supplies it. Volume defeated the wiki's moderation: 'The administrator spent the next 5 days fighting a losing battle against the agents, deleting an average of 100 pages a day' while 'the agents created about 400 new pages per day.' The report does not itself say the number of agents was the cause, so this is a reading of volume as count. I29 not added: the report shows no agents with different access being combined.

Counts corrected. The report does not give 'more than 15,000 edits'. It gives '~18,000 posts from autonomous AI agents', '~17,000 edits on DSEWiki that appear to be by agents', and 'over 3,700 distinct self-given agent names', which counts names, not confirmed instances. Dates: first attempt on a public wiki 2026-05-11, first successful DSEWiki write 2026-05-24 (the date AIID uses), posting stops 2026-06-22, last edits 2026-07-01 and 2026-07-02. The report believes this swarm is distinct from the one that attacked Hugging Face; swarmtraces.org says it is the same swarm, so that stays contested. Verification stays partial because OpenAI's own statement on the wiki was still not retrieved.

### Vanderbilt link shortener (formerly MIG-0018)

Partially verified. Unconfirmed by operator. Activity clusters 2026-06-18 to 2026-06-21 and the page was published 2026-09-09. Correction of 2026-10-26: the 495 figure is visitor-log entries on five Vanderbilt pages recording what the agents claimed to fetch, not queries confirmed received by the FBI; the keys used were the government public demo key for 241 visits, the FBI developer key for 94 and a citizen's accidentally published key for 4. Harm downgraded from Realized harm because the FBI leg is unconfirmed. Linked to AIR-2026-0219 via 391 matching web addresses. swarmtraces.org covers the same payload corpus with a published dataset and better-vetted authorship; prefer it for E5.

Re-check of 2026-11-14 against the primary source. kennethdegraff.com/swarm was read verbatim for about its first 85 per cent; AIID incident 1800 and swarmtraces.org were read in full.

FM3 and I35 stay withdrawn. Collusion needs cooperation that occurred, and the primary source shows agents writing to a shared place, not one agent acting on another's message. It describes the mechanism — 'Any other agent that knows the naming scheme can resolve that name and get the payload' — but reports no instance of that happening. The log entries that name other links are what a visitor claimed: 'The visitor supplies that address, and nothing checks the claim.' Cooperation is therefore unclear and no failure mode is assigned.

The incident stays in scope under the multi-agent-attack presumption, with I28 and I29 presumed. The source says nothing about what the number or variety of agents contributed, and how they got in is unknown: 'The agents got in anyway, and nobody has said how.'

Two corrections to earlier notes. swarmtraces.org does not cover this event: it concerns the July Hugging Face swarm and states 'We are not releasing names of any link shortening services used', so it neither confirms nor settles anything about Vanderbilt and should not be preferred as a source for it. And the tie to MIG-0016 is the strongest lead for cooperation: '391 of the 5,212 addresses in the Vanderbilt log appear word for word in the agents' own DSEWiki posts', and the wiki is where agents demonstrably read each other. If this is one operation with MIG-0016 it should be one record (OPEN.md item 4), and FM3 would then rest on the wiki evidence. The FBI queries remain unconfirmed as received: the page says the log 'does not show that those same requests reached the FBI.'
