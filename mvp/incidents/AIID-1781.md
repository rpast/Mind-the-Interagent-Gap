## Context

**Setting.** Real attack on real customer Microsoft 365 tenants via stolen ConnectWise application credentials; agents controlled by the attacker. Quote: “ARTEX is a system of LLM-driven agents that run an autonomous penetration test”

## What happened

Microsoft reported that China-aligned hackers used ARTEX, an AI penetration-testing framework, to access customers' Microsoft 365 environments through stolen credentials for ConnectWise's cloud backup services. Agents reportedly changed credentials and privileges in some environments to retain unauthorized access. The activity formed part of a global campaign; the extent of compromise and any data theft remained uncertain.

## Mechanism

**Mechanism.** Password spraying; compromise of ConnectWise app identities; sign-ins to customer tenants with stolen app credentials; Graph reconnaissance, credential and privilege changes, Key Vault secret reads. Quote: “This allowed the threat actor to operate without requiring an interactive user sign-in.”

## Agents and interaction

**Agents.** Storm-0940 ran ARTEX, a multi-agent LLM system; the number of agents and the models are not stated. Quote: “The ARTEX framework is a multi-agent LLM system written in GO with a Next.js frontend.”

**Interaction.** The source shows only the agents writing to a shared graph; it does not say any agent reads or acts on what another wrote. Quote: “The agents then accumulate the discovered assets and vulnerabilities into a graph during the penetration test.”

**Cooperation.** The agents are built to work as one framework on a shared graph, as intended by the operator; how they actually worked together is not described beyond that. Quote: “The agents then accumulate the discovered assets and vulnerabilities into a graph during the penetration test.”

**Multiplicity.** Microsoft credits ARTEX as a whole with machine speed and breadth (sign-ins to over 2,250 tenants); it does not say what the number of agents contributed. Quote: “the actor used ARTEX to accelerate the activity to machine speed”

**Objectives.** Shared: compromise targets through to data exfiltration. Quote: “from reconnaissance through data exfiltration with little needed human interaction.”
