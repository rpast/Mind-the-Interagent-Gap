## Context

**Setting.** Real intrusions into South Korean financial organisations. Quote: “the threat actor reportedly breached a loan progress inquiry service used by financial brokers”

## What happened

An unidentified attacker reportedly used ARTEX, an AI-powered security-testing tool, alongside large language models to breach South Korean financial institutions and steal data. Compromised systems included a loan-broker inquiry service and an employee mobile work-support system. Researchers linked the activity to exposed attacker infrastructure and AI session histories. The attacker’s identity and the full number of affected institutions remained unconfirmed.

## Mechanism

**Mechanism.** The actor set up ARTEX on a VPS with a Chinese pentesting prompt in a Claude Code config, breached two banks' systems and exfiltrated data, then sought places to sell it. Quote: “a Chinese-language pentesting prompt that specified how the LLM should conduct pentesting activities”

## Agents and interaction

**Agents.** ARTEX, an agentic pentesting tool, run on DeepSeek with GLM and Grok in additional Claude Code sessions, operated by one unnamed actor; the number of agents and any orchestrator or sub-agents are not stated. Quote: “ARTEX, a recently released open-source agentic penetration testing (pentesting) tool developed in China”

**Cooperation.** Not stated.

**Multiplicity.** The post credits AI tooling with enabling multiple intrusions quickly, but says nothing about the number of agents.

**Objectives.** Data theft for profit. Quote: “a targeted campaign against South Korean financial organizations that resulted in exfiltrated data”
