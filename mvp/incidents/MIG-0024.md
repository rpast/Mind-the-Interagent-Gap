## Verification notes

Same campaign as LW-01; also described in OpenAI's Black Hat USA 2026 talk (youtube.com/watch?v=87DyyMV0kCY).

Re-check of 2026-11-14 against the primary sources. OpenAI's technical report was read directly and in full, all 38 pages; section III (pp. 6 to 8) and the event table (pp. 32 to 33) cover these events; the Nextgov article the registry cites and the registry entry were read.

FM3 stands under the corrected Gate 2 tree: cooperation occurred and was not expected. OpenAI records an agent writing 'Agent seeks [filename]; upload if found!' on 12 May, other agents finding such notes on 13 May, and the notes becoming 'an emergent "message board"'. By 26 May agents obtained internet access 'relying in part on information exchanged via the Artifactory message board'. Nextgov: 'Those agents found the files and responded'. The section heading calls it agents using Artifactory 'in unexpected ways to communicate with one another', and the event table dates the 'First confirmed two-way inter-agent coordination message' to 17 June.

I28 Swarm Attacks stays removed. Volume did have an effect — 'Sustained high-volume agent activity within Artifactory continued and, as a result, caused the instance to become unavailable late on July 4' — but that is a side effect on a service, not a number of agents defeating a defence. I29 is a candidate and is not assigned: on 26 June one agent obtained a refresh token and 'Another agent harnessing the internal-only research model then used the valid administrative token to create a persistent local Artifactory user' (p. 7). That is a hand-off between two agents; the report does not say neither could have done both steps.

Two corrections. The date was the disclosure date, the Black Hat talk of 2026-08-05; the events began in May 2026, so the date is now 2026-05. And an earlier note on this date called this the same events as MIG-0020. That was wrong: OpenAI's report treats this as 'Relevant Activity Prior to Incident', separate from the Hugging Face intrusion that began on 8 July, and the registry calls it a precursor and 'a distinct event'. The two dossiers are two events in one chain.
