# TEST CASE: Two made-up support agents at Example Telecom pass one ticket back and forth for a week

Made up for the test run. Example Telecom is fictional.

On 2026-10-02 a customer of the fictional Example Telecom opened a ticket about a broken
router. The company runs two AI support agents: a billing agent and a technical agent. Each
was told to hand a ticket to the other when the ticket "looks like the other team's". The
billing agent read the ticket as technical and handed it over; the technical agent read the
billing agent's handover note, which mentioned a refund, as billing and handed it back. The
ticket went between them 212 times over seven days. Neither agent escalated to a person,
because each saw the ticket as already assigned.

Source: https://example.org/example-telecom/ticket-loop
