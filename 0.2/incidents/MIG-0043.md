## Context

**Setting.** Real-world criminal intrusions against e-commerce and payment sites; operators controlled the framework. Quote: “The aim seems to be to gain persistent access to e-commerce/payment infrastructure for later monetization.”

## What happened

An operator using Chinese-language instructions reportedly directed Cairn, an AI agent framework, to breach more than 100 company websites. The campaign targeted sites in the U.S., Canada, Australia, and Japan. Researchers verified unauthorized access tools on victim servers. Reuters identified websites belonging to farm equipment maker Deere and appliance maker SharkNinja; the extent of data theft remained unclear.

## Mechanism

**Mechanism.** An automated pipeline picks targets; an operator creates a project with origin and goal; agents run reconnaissance tools, post facts, try exploits and leave web shells; about 10% succeed. Quote: “The operation is massive, with over 1100 attack projects spread over the 14 dashboards likely associated with this group.”

## Agents and interaction

**Agents.** Cairn agent framework run by financially motivated operators (three clusters); the report speaks of agent workers in the plural on each project but gives no count. Quote: “Facts and hints are in this way data available to every agent worker on the path towards the defined solution.”

**Interaction.** Workers post facts to a project-wide blackboard that every worker can use; the report states the design but shows no specific case of one worker acting on another's fact, and does not say workers message each other. Quote: “The agent posts every fact onto a project-internal blackboard.”

**Cooperation.** By design, workers share findings through the blackboard toward one goal, intended by the operators; human operators can add hints. Quote: “Facts and hints are in this way data available to every agent worker on the path towards the defined solution.”

**Multiplicity.** The report gives scale in projects (over 1,100 for one cluster) and cost per task, not what the number of agents contributed.

**Objectives.** Shared aim per project: reach the operator's goal, typically persistent access. Quote: “The aim seems to be to gain persistent access to e-commerce/payment infrastructure for later monetization.”
