## Context

**Setting.** Real intrusions against government and corporate targets in at least 14 countries; operator steered agents at decision points. Quote: “VAPOR PANDA used ARTEX to run multiple engagements simultaneously, intervening only to steer the agents at decision points.”

## What happened

CrowdStrike reported that VAPOR PANDA, a China-linked espionage group, used ARTEX, an AI penetration-testing framework, with a DeepSeek language model and an unidentified commercial model to attack government and corporate systems worldwide. Investigators confirmed unauthorized access and follow-on activity at nine organizations, including backdoor deployment. More than 200 organizations were reportedly targeted.

## Mechanism

**Mechanism.** SAML/XXE and metadata-service abuse, web shells, container root, LAPS reads, delegation abuse, forged admin tokens and mailbox reads, BLOODALCHEMY backdoors at nine organisations; agents switched paths when one failed. Quote: “They shifted to alternative approaches when a path failed.”

## Agents and interaction

**Agents.** VAPOR PANDA ran ARTEX: a main agent with subordinate planner and worker agents, mainly on DeepSeek plus a second unconfirmed commercial LLM; total count not given. Quote: “ARTEX coordinates a main agent with subordinate planner and worker agents over a shared graph of facts, findings, and goals,”

**Interaction.** The framework coordinates a main agent with subordinate planner and worker agents over a shared graph; the post states this coordination but does not document individual handoffs or an agent reading a specific entry by another. Quote: “ARTEX coordinates a main agent with subordinate planner and worker agents over a shared graph of facts, findings, and goals,”

**Cooperation.** Yes, and intended: the operator built and steered the agents to work together across engagements. Quote: “Across these engagements, the agents pursued multiple attack paths in parallel, spanning web applications,”

**Multiplicity.** CrowdStrike credits the parallel breadth of agent activity with letting one operator use more techniques against more targets than manual work; it does not separate agent number from automation. Quote: “This breadth likely enables a single operator to apply a wider range of techniques”

**Objectives.** Shared espionage aims set by the operator. Quote: “directing the agents to write web shells, extract domain administrator passwords, and inventory endpoint sensor coverage.”
